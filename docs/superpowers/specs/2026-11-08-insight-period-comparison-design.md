# 深度剖析：七夕相对可比平日的变化

日期：2026-11-08
状态：已实现，本地验收通过（未部署）
取代范围：2026-11-07 时间筛选设计中，非全月图谱的分析目标；全月图谱继续沿用现有口径。

## 1. 问题与目标

当前日期条件已经进入查询，但默认结论仍固定解释门店横向差异；选择七夕后，「七夕」节点因窗口内全是节日而不适用。用户希望选择七夕后回答「七夕比平日有哪些变化，哪些因素与变化相关」。

选择非全月范围时，图谱切换为该时段相对可比平日的变化分析。范围恰好等于节日预设时，以节日命名；自定义范围使用日期命名。全月继续展示整体经营结构。

## 2. 页面呈现

- 主标题为「七夕相对可比平日的变化」，默认侧栏回答销售额、毛利、销量如何变化，以及订单数、客单价、货品和活动成交的相关变化。
- 顶部保留所选时段实际销售额、毛利、销量；新增对照信息必须明确标为「可比样本」，并展示该样本的本期值和对照值，不拿全期总额直接除以样本对照额。
- 对照说明写明具体日期、同店同星期匹配方式、覆盖门店与门店日数量。没有足够对照时，保留本期事实并明确说明缺少对照，不回退到宏观结论。
- 图谱围绕活动成交情况、计价金结构、订单数、客单价、毛利率和三个结果组织。商圈、店型等固定属性仅作为门店分组背景，不再以门店规模的解释度作为七夕分析的主要结论。
- 节日是本次分析的主题，不再被画成一个「窗口里没有非节日日，因此不适用」的待解释因素。星期用于匹配对照，不冒充节日的独立影响。
- 图中区分「变化拆解」和「同期观察」；不把观察到的涨幅改名为解释度，不以线宽宣称因果贡献。

## 3. 可比平日

1. 使用同一数据版本内、目标范围开始之前、非节日且早于全国克减铺开日的日期作为候选。铺开日沿用现有逐日成交结构的判定，并注明这是数据推断。
2. 每个目标门店日，匹配同一家店、相同星期几的候选日；至少有两天有效记录时，取其均值作为该门店日的对照。
3. 目标和对照都必须有实际有效记录。金额、订单、件数等必需字段缺失或不是有限数时，该门店日不进入可比样本；合法的零毛利与负毛利保留。没有记录不视为零成交、不视为营业，不推断客流或转化率。
4. 本期与对照按同一批可比门店日汇总；本期未匹配部分单独披露覆盖情况。基准为目标日期结构下的期望值，不能把两段天数不同的总额直接相比。
5. 同星期包含周末；周二仍与周二比较，不把金色星期二和普通工作日的天然差异算进七夕变化。基准仍是历史观察，不能据此宣称净节日效果。
6. 对照金额按分计算并在匹配单元取整，随后汇总；不把缺失值补零。订单和件数的对照均值允许小数，并明确这是对照期望值。

## 4. 指标与因素

- 销售额：可比样本实际额、对照额、差额和变化率；以订单数与客单价的对称拆解解释差额。两项金额贡献之和必须等于实际差额，取整余差归入最后一项。
- 销量：可比样本实际件数、对照件数、差额和变化率；展示订单数与单均件数的变化。
- 毛利：可比样本实际毛利、对照毛利、差额和变化率；以不含税销售基数与毛利率拆解。毛利率分母继续使用不含税 RSV，不换成含税实收。
- 货品：在同一可比样本比较计价金销售占比与毛利率；目前门店日面板只支持计价金与其他货品的划分，不编造更细货类贡献。
- 活动：比较可比门店日中克减 50、克减 30、金色星期二有成交的覆盖比例。此数据不等于优惠销售额份额或活动带来的增量，文案和依据明确标识。
- 门店：按商圈、店型或区域展示相对各自基准的变化；每组至少 9 家可比门店才参与分组展示，不足时说明样本不足；不能把固定属性的横向规模差异称为节日拉动因素。
- 每克让利、门槛、以旧换新若没有同口径可比数据，本次不生成对照结论，也不沿用旧图中的宏观数值填充。

变化率只在对照值大于零时展示；对照毛利为零或负数时只展示实际值、对照值与金额差。毛利率差使用百分点，不能写成百分比涨幅。

## 5. 证据边界

现有数据中七夕与全国克减重叠。所有对照结果表述为「七夕期间相对可比平日的变化」；活动、货品结构等是相关观察。范围说明和默认结论都保留「无法单独拆出七夕净效果」的限制，不把活动变化与节日变化强行分摊。

不生成缺少记录的会员、新客、客流、转化率或每日金价解释。问图和跳转智能问答时，携带本期、对照、覆盖及重叠说明，不只携带日期标签。

## 6. 实现边界

- 新增独立的可比样本计算模块与变化图谱构建模块；避免继续扩张已超过千行的 `drivers.ts`。
- Agent 范围请求复用同一数据版本的全月门店日面板与逐日数据，使用现有参数化只读查询及私有缓存；不引入模型计算、任意 SQL 或外部数据。
- 全月图谱构建与快照保持原合同。非全月新增明确的对照元数据，并复用现有节点、连线、详情、问答和 URL 入口。
- 页面切换、失败回退、请求排队、缓存隔离继续保留。新的对照数据需要接入现有问图材料与上下文，不能让问答回到全月宏观分析。

## 7. 验收

- 同店同星期匹配、节日和铺开日排除、至少两天对照、范围开始之前、缺失不补零均有合成数据用例。
- 两个等比例门店在七夕同幅增长时，不因门店规模不同得出不同增长结论；周末固定高成交但目标没有额外变化时不产生伪涨幅。
- 销售额和毛利拆解逐分守恒；零分母、负毛利、覆盖不足不给虚假变化率，不产生 NaN 或 Infinity。
- 七夕图的默认结论、节点依据、KPI 对照和问答材料来自同一个可比样本；无对照时明确展示原因。
- 全月既有快照通过；范围服务缓存与并发、前端和 Agent 类型检查通过。
- 使用真实缓存或只读服务验证七夕与全月切换，并检查页面实际显示；真实经营数据及凭据不写入仓库。
