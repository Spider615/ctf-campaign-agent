## 1. 已实现的合同

| 项目 | 实现及边界 |
|---|---|
| 自主会话 | 每轮一次 SDK query，模型自主选择动作与停止时机；不设应用层总时长或 maxTurns，没有固定六步与固定问候/月总额回复 |
| Skill | `ctf-qa`、`marketing-theory` 按相关性选择；无业务工具前置门禁；临时插件物理上只提供这两份，SDK 过滤与禁捆绑配置同时生效 |
| 工具 | inspect_dataset、analyze、simulate_scenario、draw_chart、submit_answer；精确权限名单，不开放命令、SQL、任意文件或网络 |
| 数据 | 保留单连接一致性事务与会话内缓存，维度取值完整分页；可靠源修订未就绪，未启用多连接或跨会话缓存 |
| 大结果 | 每页最多100个返回单元且含元数据不超过16000字符，比较对、情景、控制辅助依据与方法检查可续读；可按真实指标排序全量结果，游标绑定排序视图，不能把返回单元数当实际门店/活动数 |
| 正文 | 模型自由 Markdown，无逐句数字核对或独立复核；表格按格清洗身份、真实数字保留；图表绑定真实结果及父链 |
| 额度错误 | 服务账户额度耗尽统一显示“当前服务额度不足，请及时联系管理员。”；原始英文、预算与请求标识不进入客户错误提示，普通429限流/上下文超长不误报额度 |
| 完成与取消 | 无效提交不覆盖有效稿；仅完整 SDK 成功可交付；中间消息、截断、错误不能冒充答案；中断 next 及迟到会话接收窗口均有回收 |
| 过程 | 两类对话统一时间线，成功 Skill 以中文合并，失败/警告/停止状态真实；无图回答也有“本次查数结果”入口 |
| 保存 | 沿用服务端对话保存，完整请求按 UTF-8 检查2 MiB；超限不发请求、不无限重试，保留本页答案并显示未保存原因和重试入口 |
| 兼容 | 新v3/v4请求返回v4；无头/v2/未知头拒绝，不回退旧固定回复；已存旧答案继续读取 |
| 活动与附件 | 活动生成业务与门禁保持原路径，仅调整展示；附件仍用原计划式运行器及外层预算、来源和数字合同 |

本次没有删除旧分析运行器和旧 Skill，没有修改业务数据库结构或写入历史数据，没有清空原 D1。
