# 智能问答剩余质量问题修复与实测

日期：2026-10-25。范围为此前尚未通过的规则边界、会员等级两类问题，以及已通过的活动计数回归。完整客户问句、回答、计算依据与审查放在仓库外的私有验收目录，不在本文复制。

## 实现边界

仍为每轮一次 SDK `query()`，模型自主决定是否加载两份问答 Skill、使用哪些工具、调用次序及何时停止。没有增加固定业务步骤、逐句数字门禁、独立模型复核、业务轮数或总时长上限，也没有识别原问句后套回复。活动生成、附件运行器和数据授权范围未改。

## 定位到的原因

- 能力目录遗漏了维度原有的定义与依据身份；结果页把指标定义集中列出，却没有绑定到每条读数。模型需要自行还原标签、统计对象和口径。
- 数值虽有 `frameId`，目标期、参照期与筛选身份距离数值较远；对象标签又仅在外层分组，扩展解释时发生过错期引用和总体数误标为某个分组的读数。
- 模型能复述“观察不等于因果”，但仍可能把会计分解误当行为识别，例如用聚合均值推定新增交易组成，或用含其他因素的价差排除单项权益规则。末尾补限制不能修复前面的确定断言。

## 通用修复

- 目录和维度取值页保留真实定义、依据与实际授权范围；每条结果绑定自身指标定义及事实限制。
- 读数旁附实际期间、筛选、分组对象、观察/计算/假设身份；没有额外对象标签时明确标注，不自行赋予分组身份。计算依据使用原始精度。公式只展开已经在结果页向模型展示过的事实，图表证据保留与模型已读账本分开。
- 每条读数保留自己的层内/描述性/标准化身份及实际控制字段，未标记时不借方法报告替它背书。结果记录请求分组键与指定排序指标，组合数不自动缩成单字段去重，返回顺序不自动代表其他属性排名。
- 保持完整事实和筛选分页。单组接近长度预算时缩短重复范围注释并引用同页完整 frame，不裁剪样本或重算较小总体。
- 问答 Skill 用通用数学反例解释聚合关系的不可识别性，区分交易标签、规则、未知和已证实不存在。反例不是客户数据、回复范例或问题路由。
- 目录数量由本轮实际读取的去重取值产生；跳读尾页不宣称已读全量、重读不重复累计，只有首尾连通的分页链才确认总数，不增加 SQL。目录取值数仍不等于活动或其他实体数量。
- 现有目录工具增加可选的通用 `contains` 字面子串筛选，避免手翻长名单判断某个字样是否存在。MySQL 参数化查询并转义通配符，与导入快照一致区分大小写；游标、缓存与计数绑定匹配条件。它不识别活动身份或规则，没有按照问句选择固定流程。真实 SQL 已验证匹配及大小写行为。
- 基础提示只补通用证据责任；提交工具保留自由正文，不在工具说明中强调内部是否核验正文。
- 基础提示与可选指引明确用户原问题的对象边界：缺少目标维度不自动转成另一份研究；复合问题中仍有依据的部分继续回答。没有规定回复章节、字数或固定停止轮数。

## 实验与验收方法

沿用原请求，保存每轮前后源码哈希、真实 API/SQL 计数和公开工具过程；接口成功与业务通过分别判定。独立审查按实际断言核对数字、期间、样本、规则和解释强度，不因缺少真实等级或规则而强迫编造答案。合成压力题另覆盖“正式规则部分存在”和“等级维度确实存在”，防止修成一律拒答。

默认接口与模型配置保持用户现有选择。另做提高推理强度、同服务更强模型的隔离对照，但均仍观察到错误，未采纳为日常配置。推理参数及兼容映射参照[官方推理模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)和[官方兼容接口说明](https://api-docs.deepseek.com/guides/anthropic_api/)；这些文档不证明业务回答正确。中止的实验明确记为取消，不计作通过或耗时达标。
