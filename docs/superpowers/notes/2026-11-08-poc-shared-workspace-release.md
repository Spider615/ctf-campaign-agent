# POC 共享空间发布验收

## 发布范围

用户明确要求部署跨浏览器共享修复，并确认其他浏览器能读取此前的数据。

发布副本从现有线上 GitLab `main` 的 `4f60c558a3721832696112d7ad3a7bec80297725` 建立，仅应用共享空间修复。未包含源工作区的七夕对照分析提交、洞察页面调整或依赖锁文件修改。

沿用原服务 `ctf-campaign-agent`、原公网地址和持久化配置：D1 `/data/d1`，附件 `/data/attachments`。不增加环境变量，不迁移、重建或清空线上数据库。
