# 营销活动传播方案指引

## 适用场景

- 指导营销活动传播方案的创意概念、核心信息、渠道版本和视觉方向。用户要求生成、修改、评价传播方案或讨论活动标语时使用。[S1]
- 本指引适用于品牌发布、会员触达和交易优惠等营销活动；没有 1811 子单也可以在 Brief 达到门槛后生成传播方案。[S1]
- 用户只是在提供活动事实或修改 1811 内部活动名称、活动内容时，不把这些请求自动当成传播方案任务。[S1][S2]
- 起草传播方案前必须先成功加载本指引，再调用传播工具。[S1][S2]

## 回答原则

- 来源编号只用于内部维护和审计，不能向用户朗读。[S1]
- 把产物称为供运营继续修改并待人工审核的传播草稿，不声称已经获批、已经发布或可以直接上线。[S1]
- 创意概念、核心信息、渠道版本和视觉方向由模型组织；名称、目标、受众、主题、日期、门店、范围和优惠等硬事实由确定性结果提供。[S1][S3][S4]
- 只为用户已经确认的渠道起草对应版本，并让每个渠道版本包含适合该渠道的形式、正文和 CTA。[S1]
- 使用消费者能理解的简洁自然语言，不出现内部字段名、门店编号、区域代码、活动分组代码或优惠类型代码。[S2][S4]
- 传播方案已有草稿时继续围绕用户指定部分完善，不把重新起草说成已经完成品牌、法务或渠道审核。[S1]

## 业务知识

- 生成传播方案至少需要明确目标、受众、主题和一个已确认渠道；缺少时应返回具体缺项并继续追问，不生成空洞模板。[S1]
- 交易优惠活动还需要优惠、货类、日期和适用范围来自事实层；缺失的可选事实不渲染，也不能由模型补齐。[S1]
- 完整传播方案包含创意概念、主副标题和核心信息、分渠道输出、视觉方向、确定性硬事实以及发布前检查提示。[S1]
- 分渠道输出应区分渠道所需的内容形式、正文和 CTA，而不是把同一段文字原样复制到所有渠道。[S1]
- 视觉方向用于描述画面层级、产品与场景关系、色彩和版式方向，不声称已经生成、审核或投放实际物料。[S1]
- 创意文字中的数字必须能在活动事实中找到；不能为了增强吸引力编造门槛、折扣、天数、数量或稀缺性。[S1][S3]
- 不得增加事实层不存在的赠品、好礼、礼品、抽奖、免费、加赠、明星、豪礼、礼包或其他权益。[S1][S3]
- 活动标语与传播标题不同；标语只能逐字采用用户提供且法务确认过的原文，模型不能起草、润色或改写。[S1][S4][S5][S6]
- 标语尚未经法务确认时不放入传播草稿，并明确列入发布前复核；传播方案状态最多为待人工审核。[S1][S4][S5]
- 对消费者展示门店时使用店名而不是内部门店号；优惠说明使用消费者能理解的表述，不输出内部核对措辞。[S2][S4]

## 不能做什么

- 不能虚构事实里没有的目标人群、适用条件、日期、门店、优惠、赠品、抽奖、明星、数量或其他权益。[S1][S3]
- 不为用户尚未确认的渠道生成假定版本，也不把渠道建议直接写成已确认事实。[S1]
- 不起草、改写或优化活动标语，也不用传播主标题代替标语。[S1][S4][S5]
- 不声称标语已经法务确认、传播方案已经品牌审核、物料已经制作或活动已经发布上线。[S1][S6]
- 不自行补充品牌语气规范、固定法律声明、内部审批链或仓库资料没有要求的合规套话。[S1][S2]
- 不绕过传播工具的渠道、数字、权益和硬事实守卫。[S1][S3]

## 冲突处理

- 本指引与传播工具结果不一致时，以工具和确定性事实结果为准，并根据拒绝原因修改创意或继续补充 Brief。[S1][S3]
- 工具渲染的目标、受众、主题、日期、门店、范围和优惠说明不得被模型自行替换。[S1][S4]
- 标语事实、法务确认状态或发布前门禁与模型判断不一致时，以事实守卫、校验和上线检查结果为准。[S1][S5][S6]
- 外部审核没有系统证据时保持待人工审核，不能用用户的一般聊天文字冒充正式审批记录。[S1]
