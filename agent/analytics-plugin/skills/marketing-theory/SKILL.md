# 营销方法参考

这些是按问题选择的理论卡，不是分析流程、必用清单或回答章节。只采用有助于当前判断的内容；不必每题加载本 Skill，也不必遍历全部卡片。按当前 capabilities、定义和实际覆盖判断能做什么，区分 MySQL 与导入快照；字段存在不等于分析工具已实现对应模型。缺少一项证据时，继续完成其余可做的分析，不用固定试点天数或套话代替取证。

出处的“正文”“摘要”“书目／目录”表示已核实的阅读层级，不是同一种证明强度。表达方法、定义恒等式、会计条件、行业口径和情境性实证各有用途；外部研究不是本库经营事实，也不提供通用效果参数。未核实的首创归属、正文页码和效应量不补写。以下链接用于标明依据，不授予浏览、文件读取、自由 SQL 或脚本权限；只用本回合开放的受控工具。

## 直接回答与表达层级

- 适用：需要把经营判断讲清楚，或用户要求选择、建议与方案。
- 所需证据：本题实际得到的事实、关键条件及尚未确定之处；表达结构本身不产生证据。
- 判断：可先回答用户最关心的决定，再展开足够的依据；短问题可以一句话。复杂问题怎样分组、是否设标题，由内容决定。
- 边界：结论先说不等于结论正确，也不要求固定板块、三点建议或每题都讲理论。

依据：Barbara Minto [作者官网概念说明](https://www.barbaraminto.com/concept)，已读网页正文，未读图书全文；这是表达与思考组织方法。

## 销售指标树与算术拆解

- 适用：销售为什么变化，金额增长来自订单、件数还是单位实收，或需要核对指标是否一致。
- 所需证据：同一版本、期间、币种与销售范围的实收 A、去重有效订单 O、件数 Q；分母为正且覆盖一致。缺订单标识时需保留覆盖偏差，净销售与回收不能直接套用销售均值。
- 判断：定义上 A＝O×(A/O)＝O×(Q/O)×(A/Q)。汇总能取得登记指标，可结合现有拆解研究数量、单位实收与结构；每单件数是派生比率，当前拆解不等于已实现这棵树的完整因子贡献。比率先汇总分子分母，跨组订单不直接相加，各因子涨幅也不能直接相加。
- 边界：订单与单均只覆盖筛选内成交部分，不是完整购物篮或顾客人数；件均变化含金重、金价与货品结构，不自动是调价或促销原因。客流不存在时，不能进一步编造进店转化。

依据：Perdikaki、Kesavan、Swaminathan（2012）[零售客流研究](https://doi.org/10.1287/msom.1110.0356)，仅读出版社摘要中的交易、篮子及转化定义；件数扩展是依定义作的代数推导，不是论文已验证的因果树。

## 促销销量的来源与净增

- 适用：活动是否带来新需求，还是发生货品替代、购买提前、囤货或跨店转移。
- 所需证据：活动规则、暴露与资格，促销前中后数据、替代货品或竞争范围，以及能支持未干预结果的比较；消费者切换与囤货还需要纵向购买信息。
- 判断：现有汇总、比较、拆解和扫描能定位观察差异及其结构，提示值得核对的跨品、跨店或跨期变化。无客户轨迹时仍可完成这些描述，只收窄净增和行为判断。囤货可能前移购买，也可能有其他消费或替代效应，不预设全部有益或全部损失。
- 边界：算术 decompose 不是文献的购买决策或门店回归模型。活动销量、品类扩张、市场净增和利润分别定义；不能将替代、蚕食与跨期项无边界地重复相加，更不能发布本库未识别的净增比例。

依据：Gupta（1988）[何时买、买什么、买多少](https://doi.org/10.1177/002224378802500402)、van Heerde 等（2004）[门店促销抬升分解](https://research.rug.nl/en/publications/decomposing-the-sales-promotion-bump-with-store-data/)、Ailawadi 等（2007）[促销囤货分解](https://doi.org/10.1509/jmkr.44.3.450)，均仅读原论文摘要；样本机制及分解比例不移植到珠宝。

## 可比窗口、共同门店与对照

- 适用：两个活动、时期或门店群谁表现更好，或需要判断差异是否稳定。
- 所需证据：可解释的目标与参照、时间覆盖、共同观察门店、商品与材料结构、同期环境；因果判断另需干预分配、未受影响的参照及可信识别假设。
- 判断：可按问题使用比较、控制层、标准化、替代窗口或大店大单剔除。窗口长短不同可看日均，同时说明分母是有成交日期，不自动是营业日。结合覆盖差异判断共同门店能改善什么、还留下什么偏差。
- 边界：共同观察门店不等于企业正式同店，源同店字段也需核对定义。有对照、控制变量或稳健性结果不自动证明因果；当前工具没有因此获得合成对照、随机实验估计器或统计因果置信度。

依据：Abadie、Diamond、Hainmueller（2010）[合成对照原文](https://economics.mit.edu/sites/default/files/publications/Synthetic%20Control%20Methods.pdf)，已读引言与 §2.2–2.4；Gordon 等（2019）[观察估计与实地实验对照](https://doi.org/10.1287/mksc.2018.1135)，仅摘要。门店应用是方法类推，不是两文已验证本库效果。

## 收入持平与维持原利润

- 适用：额外让利要补多少成交量，或某优惠在明确成本条件下能否维持原利润。
- 所需证据：基准销量 Q₀、原单位售价 P、单位变动成本 c、同期间总固定成本及新增费用；d 是相对 P 的降价比例，m＝(P−c)/P 是降价前贡献毛利率。币种、销量单位与销售组合须一致。
- 判断：统一比例降价且 0≤d<1，固定结构下收入持平的额外销量比例为 d/(1−d)。只有 m>d≥0、单位变动成本及总固定成本不变、单品同质或组合固定且无漏计费用时，维持原利润的额外销量比例才为 d/(m−d)。新增活动费、抽佣变化、退货或成交挪动会改变条件；整件／整单决策还需向上取整。
- 边界：m≤d 时，不能靠有限补量维持原有正贡献。利润条件不是需求预测，也不是企业由亏损到零的绝对盈亏平衡量。源零售毛利不能直接代入 m。`simulate_scenario` 按声明能力逐单位到分并封顶，输出收入情景与显式净量假设，不自动计算贡献成本、利润持平或最优折扣；可作条件代数分析，不能假称利润已由工具测出。

依据：OpenStax（2019）[管理会计 §3.1](https://openstax.org/books/principles-managerial-accounting/pages/3-1-explain-contribution-margin-and-calculate-contribution-margin-per-unit-contribution-margin-ratio-and-total-contribution-margin)、[§3.2](https://openstax.org/books/principles-managerial-accounting/pages/3-2-calculate-a-break-even-point-in-units-and-dollars)，已读章节正文。两个补量公式是依定义推导，不声称教材原文直接写出或已找到最早作者。

## 黄金珠宝的价格、重量与换购

- 适用：金额与销量方向不一致、黄金与其他货类结构变化、克减与折扣比较，或换购收入解释。
- 所需证据：件数、金重及其单位／纯度定义、货类、材料与计价规则；剥离金价还需同期真实基准或门店金价及工费；换购现金还需新旧货配对、抵扣和补现金。
- 判断：可先比较已有实收、件数、金重与货品结构，每克比率保持同货类同材料。计重与按件定价、行业需求量与 POS 实收分别理解；没有完整价格组成时，仍能描述成交结构，但不强行分离金价与优惠。换购相关的销售、退货和回收候选分列解释。
- 边界：牌价每克不是实际金价，牌价实收差额不是完整优惠，固定价商品也并非完全不受金价影响。行业调查和统计定义不能补造本库库存、工费、纯度或结算关系；回收候选不能直接确认为旧金抵扣、活动补贴或新增现金。

依据：世界黄金协会 [2023 中国珠宝定价调查](https://www.gold.org/goldhub/research/market-update/2023-chinese-jewellery-market-insights-gold-continues-to-lead-the-market)图 11–12 周边正文，以及 [2025 全年统计定义](https://www.gold.org/goldhub/research/gold-demand-trends/gold-demand-trends-full-year-2025/notes-definitions)的金饰消费与回收定义正文。它们是行业口径，不是本库的价格或会计凭证。

## 门槛促销与追加购买

- 适用：满减门槛是否可能引导追加购买，怎样理解自然达标与凑单。
- 所需证据：完整订单、真实优惠资格与叠加规则、阈值附近的金额分布、未成交与放弃信息；识别促销效果另需合适的未促销或随机对照。
- 判断：门槛可能成为支出目标，也可能因目标及规则而降低支出；将其作为待检验机制。现有订单稳健性接口只有 p50/p90/p99，可描述成交部分的分布位置，不能据此画阈值附近直方图。即使以后有密度堆积，也先视为线索而非已确认的行为效果。
- 边界：`order_threshold` 情景仅向筛选内订单成交部分应用假设门槛，不恢复完整购物篮、历史资格或消费者凑单。不能据分位数计算凑单人数、最优门槛、放弃率或真实净增；有金额字段也不等于当前工具已提供所需分布算法。

依据：Lee、Ariely（2006）[购物目标与条件促销](https://web.mit.edu/ariely/www/MIT/Papers/ShopGoals.pdf)，已读实验设置、实验 2／3 与讨论；Kulkarni、Yuan（2025）[门槛距离与追加搜索](https://doi.org/10.1002/mar.22200)，仅摘要。便利店购买与追加搜索均不能直接转换为珠宝净利润。

## 折扣的表述方式

- 适用：同一经济优惠用金额还是百分比表达，或需要提出文案验证方向。
- 所需证据：相同商品、基准价格、优惠资格与经济力度，以及触达、消费者认知和选择的测量；比较文字时不要同时偷换权益。
- 判断：在等价优惠下可提出不同表达的候选方案和要观察的认知差异；已有成交数据能描述不同优惠标签的历史表现，却没有隔离文案作用。克减与打折还可能改变单位、资格和力度，不能直接当同一个优惠的两种说法。
- 边界：论文中的深折扣及实验条件不能省略，也不能推出百分比永远更好。没有传播与认知数据时，不报本品牌最优表述、感知提升或长期收益。

依据：DelVecchio、Krishnan、Smith（2007）[Cents or Percent?](https://doi.org/10.1509/jmkg.71.3.158)，仅读原论文摘要中的条件性比较，未核实正文效应量。

## 交易、门店细分与目标选择

- 适用：哪里有机会、哪些成交群值得关注，以及怎样把分组观察转为目标选择与定位思路。
- 所需证据：真实分组、样本、规模、收益与资源；判断人群还需共同需求、营销响应、可触达性及行动条件，定位还需价值主张与消费者认知。
- 判断：可用现有门店、商品和交易维度比较结构、份额与表现，选出与用户目标有关的具体机会；描述销售差异与选择投放对象分别论证。某个客户指标缺数据时，仍可给已有证据支撑的经营做法，明确其适用对象。
- 边界：高销售组不自动是最佳投放组。门店所在地不是顾客住址与收入，买过某类商品不证明购买动机；会员销售标识不是名单、等级、新客或复购。会员分组在不同源中可用性不同，先查定义，不将其自动改名为 RFM 或 CLV。

依据：OpenStax（2023）营销学 [§5.1](https://openstax.org/books/principles-marketing/pages/5-1-market-segmentation-and-consumer-markets)、[§5.4](https://openstax.org/books/principles-marketing/pages/5-4-essential-factors-in-effective-market-segmentation)、[§5.5](https://openstax.org/books/principles-marketing/pages/5-5-selecting-target-markets)、[§5.6](https://openstax.org/books/principles-marketing/pages/5-6-product-positioning)正文。Smith（1956）仅核书目，Kotler 等第 16 版仅核目录，不以两者未读正文或首创归属背书。

## 促销频率与参考价格

- 适用：是否长期依赖折扣，或担心顾客价格预期和品牌选择受到影响。
- 所需证据：多期促销频率、深度、真实暴露及成交，消费者预期的直接测量与合适比较；时间窗口须匹配购买周期。
- 判断：条件具备时可描述多期促销与成交变化，并提出价格预期风险及后续要测什么。只有单期成交时，仍可完成优惠和货品结构分析，把长期心理机制保留为待检验问题。
- 边界：消费者未来预期价格不是源表牌价或实收的直接同义词。单月折扣与金额相关不能证明参考价格侵蚀，不能声称每次促销必然永久伤品牌，或给出通用安全频次和固定恢复天数。

依据：Kalwani、Yim（1992）[消费者价格与促销预期实验](https://doi.org/10.1177/002224379202900108)，以及上述 DelVecchio 等（2007），均仅摘要；支持有条件的机制，不支持本品牌效果量。

## 客户与效果指标的数据缺口

这些缺口只限制依赖它们的结论；按当前能力决定可做的补充，不把替代指标伪装成原问题的答案。

- RFM 与观察复购需要稳定客户关联、有效交易及统一观察窗口；订单不是客户，首次被观察不一定是新客，没买也不一定已流失。可先描述会员销售行和成交结构。依据 Fader、Hardie、Lee（2005）[RFM 作者稿 §2 及输入／假设段落](https://www.brucehardie.com/papers/rfm_clv_2005-02-16.pdf)，已读相关正文；[复购模型作者重印](https://www.brucehardie.com/papers/018/fader_et_al_mksc_05.pdf)已读引言和输入部分，预测不等于观察复购率。
- 个体 CLV 需要客户历史与未来收益假设；群体估值不必一律有逐客 ID，但仍需可识别的 cohort、留存、利润、获客及折现依据。历史实收不能改名为未来价值。依据 Gupta、Lehmann、Stuart（2004）[Valuing Customers](https://business.columbia.edu/faculty/research/valuing-customers-0)，仅摘要。
- 客流转化要同店同期客流分母、计数规则与对应交易；无客流仍可分析成交订单、件数与结构，不能判断下降来自进店减少还是转化降低。依据上述零售客流研究的摘要定义。
- 利润型营销回报需要费用、贡献成本、期间及可信反事实，折扣已反映在实收时不重复扣减。没有这些条件，可给收入比较、费用成立条件或收入情景，不能将销售差额／费用称为已识别的利润 ROI。依据 Farris 等（2015）[MROI 原文](https://henrystewartpublications.com/wp-content/uploads/2025/02/Hanssens.pdf)第 270–271 页；这是本文选择的利润型口径，不是文献唯一允许的估值形式。
- 剥离金价与换购现金需要真实报价、纯度、工费和新旧货结算关联；不足时分清金额、件数、金重、退货和回收候选，不从行业报告填补本库字段。依据上述黄金协会行业定义，具体最低数据条件是项目应用判断。
